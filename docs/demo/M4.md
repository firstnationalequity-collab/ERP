Users: `demo.qc_analyst`, `demo.qc_manager`, `demo.storekeeper`, `demo.system_admin` (password = `DEV_DEMO_PASSWORD`). Before: `pnpm db:seed:demo-data`, post GRNs for a QC-required item (demo/M3.md) so lots sit in QUARANTINE. GRN expiry `06-2028` stores 30-06-2028.

## Steps
1. **demo.qc_analyst** → Quality control → Specifications → new version for the item: Assay 98–102 % (assay), Water ≤ 0.5 % (water), Identification (text "Complies"); Submit. **demo.qc_manager** → Approve, e-sign. Expected: v1 APPROVED.
2. **demo.qc_analyst** → Sample queue → open the OPEN request → Take sample: test 2, retention 1. Expected: SAMPLED, lot UNDER_TEST, spec v1 pinned, stock 3 lower, QC_SAMPLE journal Dr 6400 / Cr 1310.
3. Enter Assay 99.12345, Water 0.2, Identification "Concordant" + Complies. **demo.qc_manager** → Results review → Review, e-sign (REVIEWED).
4. **demo.qc_manager** → Lot disposition → open the lot → Approve, e-sign. Expected: APPROVED, assay 99.1235 / water 0.2000, request CLOSED.
5. Second lot: sample, enter Assay 96.5 (FAIL). Expected: the assay shows "OOS opens at review"; no Re-test button. Review it. Expected: tag OOS-2627-00001 open.
6. Lot disposition → the lot: approval blocked ("OOS investigation … is open"); Reject is still possible (do not reject yet).
7. **demo.qc_manager** → OOS investigations → OOS-2627-00001 → Invalidated, cause Lab error, description "Wrong standard weight in the calculation" → Close with e-signature. Expected: CLOSED / INVALIDATED; the result shows "invalidated".
8. **demo.qc_analyst** → Sample queue → the second lot → Re-test the assay: 99.5 with a reason. Expected: 99.5 PASS tagged "re-test · OOS-2627-00001"; 96.5 under Superseded, unchanged. Review, then approve: assay 99.5000.
9. Third lot: sample, Assay 96 (FAIL), review → OOS-2627-00002 → close as Confirmed. Expected: no Re-test button; Lot disposition → Reject lot, e-sign → REJECTED (destroy / return only, with a QA witness).
10. Fourth lot, not sampled: Lot disposition → filter Quarantine → category Damaged container + description → Reject, e-sign. Expected: REJECTED, request CANCELLED.
11. **demo.system_admin** → Settings: company.name, company.address, company.drap_licence_no (optional: upload a PNG to core.companies/1 and put its id in company.logo).
12. **demo.qc_manager** → Certificates of analysis → second lot → Issue certificate, e-sign. Expected: COA-2627-00001 v1; the PDF header shows the settings; the assay line shows "re-test; OOS-2627-00001 INVALIDATED (LAB_ERROR)".
13. Same row → Re-issue, e-sign with reason "Address corrected". Expected: v2 CURRENT with the reason printed; v1 SUPERSEDED and its PDF still opens.

## Must be refused
- Re-testing a failed result before review → OOS_REQUIRED; while its OOS is open → OOS_OPEN; after CONFIRMED → OOS_NOT_INVALIDATED.
- Approving a lot with an open OOS → OOS_OPEN; with an invalidated result not re-tested yet → QC_RETEST_REQUIRED; with a failed test → QC_TEST_FAILED.
- Closing an OOS as the analyst who entered the failed result → SEGREGATION_OF_DUTIES; demo.qc_analyst / demo.qa_manager closing → 403; Invalidated without cause and description → refused.
- Approving before review (QC_RESULTS_NOT_REVIEWED) or with a test missing (QC_RESULTS_INCOMPLETE); rejecting without a failed result and without category + description → QC_REJECT_CATEGORY_REQUIRED.
- Approving / rejecting an FG lot → FG_LOT_QA_DECIDES; a second certificate for one approval → ALREADY_EXISTS; re-issuing a SUPERSEDED version → INVALID_TRANSITION; demo.qc_analyst issuing or re-issuing → 403.
