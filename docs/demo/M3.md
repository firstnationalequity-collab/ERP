# M3 demo: purchase order → goods received → landed cost (tasks 3, 3b, 4)

Users: `demo.purchase_officer`, `demo.purchase_manager`, `demo.storekeeper`, `demo.finance_manager`, `demo.warehouse_manager`, `demo.qa_manager` (password = `DEV_DEMO_PASSWORD` in `.env`).
Before: one ACTIVE vendor, one ACTIVE RM item with an APPROVED source, location QUAR, FY 2026-27 periods OPEN.

## Steps
1. **Purchase officer** → Purchase orders → New: LOCAL, the vendor, RM 100 KG at 50.125 → Save, Submit. **Purchase manager** → My approvals → Approve (password). Expected: PO APPROVED.
2. **Storekeeper** → Goods received (GRN) → Receive against a PO: type the PO number, Enter. Expected: ordered 100, max 102 (2%), source pre-picked.
3. Qty 60, containers 3, batch, expiry, location QUAR → Save draft. Expected: GRN-2627-… DRAFT.
4. **Purchase officer** opens the draft GRN → Landed costs → Add a charge: FREIGHT 600, by value, billed by the vendor. Add another: IMPORT_ST (sales tax at import) 500.
   Expected: both DRAFT, "With the GRN".
5. **Storekeeper** → Post. Expected: POSTED; lot ML26-… QUARANTINE, QC sample OPEN; both charges POSTED. Landed costs → open LC-2627-…:
   allocation 600 into the lot. Lot cost = (3,007.50 + 600) ÷ 60 = 60.125000. Journals: Dr Stock / Cr Landed-cost clearing 600; Dr Input sales tax / Cr clearing 500.
6. Print labels: 3 labels (QUARANTINE, item, lot barcode, batch, dates). The PO shows PARTIALLY_RECEIVED, received 60.
7. Receive a SPARE item 10 at 100. Expected: lot APPROVED, no QC sample.
8. **Purchase officer** → open that GRN → Add a later bill: INSURANCE 1,000, today → Landed costs → open → Post.
   Expected: all 1,000 into the lot (10 of 10 still held), posted on the charge date. (A partly used lot sends the used share to price variance; no screen consumes stock before M6, so the API tests show it.)
9. Import PO (USD vendor): **Finance manager** enters the USD rate for the PO and GRN dates first. Expected: unit cost = USD price × the GRN-date rate.
   On its draft GRN, a CD (customs duty) charge "by GD amounts per PO line" with the GD figures: each line gets its own duty.
10. **Storekeeper**: a new DRAFT GRN with a charge → Cancel GRN (reason). Expected: GRN and its charge CANCELLED.
11. **Warehouse manager**: an untouched POSTED GRN without posted charges → Reverse (password + reason). Expected: REVERSED, reversal journal, QC sample CANCELLED, PO quantities back.
12. **Finance manager** → Landed costs → Charge types: the 8 types; add one (e.g. DEMURRAGE, capitalised, by weight); deactivate it.

## Must be refused
- Receive 103 on a 100 line → **OVER_RECEIPT**. The PO's creator or approver posts its GRN → **SEGREGATION_OF_DUTIES** (403).
- Approved source blocked after the draft, then Post → **AVL_NOT_APPROVED**. No USD rate within 3 days → **RATE_MISSING**.
- Post or edit a POSTED GRN again → **RECORD_LOCKED**. Storekeeper reverses a GRN → 403; after the lot moved → **GRN_LOTS_IN_USE**.
- Reverse a GRN that has a posted landed cost → **GRN_HAS_LANDED_COST**.
- Storekeeper adds a landed-cost charge → 403 (Purchase officer only). Purchase officer adds a charge type → 403 (Finance only).
- GD amounts that do not add up to the charge, a later bill dated before the GRN, or one dated in a closed month (→ **PERIOD_CLOSED**) → refused.
- Shelf-life setting 50% and a line with 38 of 365 days left → **SHELF_LIFE_TOO_SHORT**. "Needs QC" off without QA countersign → **COUNTERSIGN_REQUIRED**.
