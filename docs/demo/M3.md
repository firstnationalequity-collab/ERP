# M3 demo: purchase order → goods received (task 3 + owner answers 25-11)

Users: `demo.purchase_officer`, `demo.purchase_manager`, `demo.storekeeper`, `demo.finance_manager`, `demo.warehouse_manager`, `demo.qa_manager` (password = `DEV_DEMO_PASSWORD` in `.env`).
Before: one ACTIVE vendor, one ACTIVE RM item with an APPROVED source (Masters → Approved sources), one location (e.g. QUAR), FY 2026-27 periods OPEN.

## Steps
1. **Purchase officer** → Procurement → Purchase orders → New: LOCAL, the vendor, RM item 100 KG at 50.125. Save, Submit.
   Expected: status PENDING_APPROVAL, "PKR (approval value)" filled.
2. **Purchase manager** → My approvals → open it → Approve (password). Expected: PO APPROVED.
3. **Storekeeper** → Procurement → Goods received (GRN) → Receive against a PO. Type the PO number, press Enter.
   Expected: the line shows ordered 100, received 0, max 102 (2% tolerance); the approved source is pre-picked.
4. Enter qty 60, containers 3, manufacturer batch, expiry; pick location QUAR; Save draft. Expected: GRN-2627-… in DRAFT.
5. Open it → Post → confirm. Expected: POSTED; the line shows lot ML26-… in QUARANTINE, QC sample OPEN,
   unit cost 50.125000, value 3,007.50 PKR, journal SJ-… named under "Posted".
6. Print labels. Expected: a PDF with 3 labels (one per container): QUARANTINE, item, lot barcode, batch, dates.
7. Purchase orders → open the PO. Expected: PARTIALLY_RECEIVED, received 60.
8. Receive the remaining 40 (step 3–5). Expected: PO RECEIVED.
9. Import PO (foreign vendor, USD): Finance manager enters the USD rate for the GRN date first (Exchange rates).
   Expected: the GRN shows the GRN-date rate and its date; unit cost = USD price × that rate.

10. Receive a SPARE item. Expected: its lot is APPROVED, QC sample "—" (spares need no QC).
11. **Storekeeper**: a new DRAFT GRN → Cancel GRN, reason "wrong PO". Expected: CANCELLED.
12. **Warehouse manager**: open an untouched POSTED GRN → Reverse, password + reason. Expected: REVERSED, reversal
    journal SJ-… shown, QC sample CANCELLED, PO back to APPROVED / PARTIALLY_RECEIVED.

## Must be refused
- Storekeeper receives 103 on a 100 line (2% tolerance) → **OVER_RECEIPT**.
- A user who created or approved the PO posts its GRN → **SEGREGATION_OF_DUTIES** (403).
- QA blocks the approved source after the draft is saved, then Post → **AVL_NOT_APPROVED**; nothing is posted.
- Import GRN with no USD rate within 3 days of the GRN date → **RATE_MISSING**.
- An API line without manufacturer batch, mfg, expiry and retest dates, or already expired → refused (VALIDATION_FAILED).
- Edit or post a POSTED GRN again → **RECORD_LOCKED**.
- Storekeeper reverses a GRN (no `purch.grn.reverse`) → 403; Warehouse manager reverses after the lot was moved → **GRN_LOTS_IN_USE**.
- With setting `purch.grn.min_shelf_life_pct` = 50, a line with 38 of 365 days left → **SHELF_LIFE_TOO_SHORT**.
- Items: turning "Needs QC" off on an active RM without a QA Manager countersign → **COUNTERSIGN_REQUIRED**.
